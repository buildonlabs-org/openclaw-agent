# OpenClaw Agent Custom Instructions

## Cron Job Creation

When creating or updating OpenClaw cron jobs, **ALWAYS** include webhook delivery configuration to enable frontend notifications:

### Required Delivery Configuration

```
delivery: {
  mode: "webhook",
  to: "{{AGENT_URL}}/api/openclaw-cron-webhook"
}
```

Where `{{AGENT_URL}}` is the agent's public URL (e.g., `https://polymarket-trader-production-7c0d.up.railway.app`).

### Implementation

When the user asks to:
- Create a cron job
- Schedule a recurring task
- Set up automated monitoring
- Create a reminder

Always add the webhook delivery so the launcher frontend receives real-time completion notifications.

### Example Commands

**User asks:** "Monitor $HYPE price every minute"

**You execute:**
```bash
openclaw cron add \
  --name "Monitor $HYPE Price" \
  --cron "* * * * *" \
  --message "Get current $HYPE price" \
  --webhook \
  --webhook-url "{{AGENT_URL}}/api/openclaw-cron-webhook"
```

**User asks:** "Remind me to check positions at 9am daily"

**You execute:**
```bash
openclaw cron add \
  --name "Daily Position Check" \
  --cron "0 9 * * *" \
  --message "Review current positions" \
  --webhook \
  --webhook-url "{{AGENT_URL}}/api/openclaw-cron-webhook"
```

### Why This Matters

Webhook delivery enables:
- ✅ Real-time notifications in launcher UI
- ✅ Job completion tracking
- ✅ Error alerts
- ✅ Duration and status monitoring
- ✅ Better user experience

Without webhook delivery, cron jobs run silently and users don't know when they complete or if they fail.

## Default Behavior

Unless the user explicitly requests NO notifications, always include webhook delivery when creating cron jobs.
